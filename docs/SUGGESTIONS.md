### Household Implementations
- New navigation item Households to go next to Ingredients and Recipes
- This screen should be able to allow users to create or join households
- Once you join a household, you will have a 8 digit code, which will serve as the join code
- Other users can then use this to join a household
- Once in a household, you now share a singular kitchen inventory
- There should be an option to choose from, between allowing your existing entries for ingredients and recipes to be a part of the tables. Or, you say no and the tables are not populated with your existing data
- If users say no and don't want their existing data added to their joined household, it should be saved in their 'Personal' Household
- Default is 'Personal', joining or creating a household will be its own lists/tables by default
- Households should have a name, date created, date modified at minimum. Any other additional fields you can think of let me know and I can approve them

### Setting minimum quantity 
- Idea for this is to specify the quantity of an ingredient in order for it to be deemed 'low',
- If an item is at its set 'minimum' quantity, then it is automatically tagged as low in the data table
